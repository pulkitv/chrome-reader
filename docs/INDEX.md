## Documentation standards

- Every markdown file in this folder must stay under 1,000 lines.
- If a document exceeds that limit, split it into numbered parts and keep a small hub file as the canonical entry point.
- Update `PROJECT_SUMMARY.md` and `PROJECT_ARCHITECTURE.md` together whenever architecture/contracts/invariants change.
