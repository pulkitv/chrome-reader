ReadEasy Privacy Policy

Last updated: February 28, 2026

ReadEasy ("the extension") provides a distraction-free reader view by extracting article content from the current page. This privacy policy explains how data is handled.

Data We Collect

We do not collect, transmit, or sell personal data. The extension processes the current page’s website content (text, images, links) locally on your device to render the reader view, manage your reading list, and generate exports (HTML/EPUB). Text-to-speech playback uses your browser’s built-in speech engine locally on your device. If you use the “Add to List” or “Reading List” features, the full article content (including images) is stored locally in your browser’s IndexedDB and Chrome storage for your use only. If you click the “Save for later” / “Send to Web App” button, the current article’s HTML (and styling) is sent to the web app you choose to open.

Data We Store

We store user data only in your browser, never on external servers. Data stored includes:

  • Theme selection
  • Font size
  • Content width
  • Reading list metadata (title, URL, site, date) in Chrome local storage
  • Full article HTML (including images) in your browser’s IndexedDB for the Reading List and EPUB merge features

The current article may be stored temporarily in session storage to display in the reader tab. No data leaves your device unless you explicitly use export, merge, or share features (e.g., download EPUB, send to web app).

Data Sharing

We do not share or sell data with third parties. When you explicitly use “Save for later” / “Send to Web App,” the article content (HTML and CSS styling) is transferred to the destination web app you open for the purpose of rendering the article.

Remote Code

The extension does not load or execute remote code. All JavaScript is bundled with the extension.

Permissions

  • activeTab: Access the current page only after the user clicks the extension icon.
  • scripting: Inject the content extraction script into the active tab.
  • storage: Save preferences, reading list metadata, and temporary article data.
  • sidePanel: Display the native Chrome side panel for your reading list.
  • declarativeNetRequest: Set referrer headers for CDN images to load correctly.
  • contextMenus: Add context menu for quick access to the reading list.
