ReadEasy Privacy Policy

Last updated: February 13, 2026

ReadEasy ("the extension") provides a distraction-free reader view by extracting article content from the current page. This privacy policy explains how data is handled.

Data We Collect

We do not collect, transmit, or sell personal data. The extension processes the current page’s website content (text, images, links) locally on your device to render the reader view and generate exports (HTML/EPUB). Text-to-speech playback uses your browser’s built-in speech engine locally on your device. If you click the “Save for later” / “Send to Web App” button, the current article’s HTML (and styling) is sent to the web app you choose to open.

Data We Store

We store user preferences locally using Chrome storage:

  • Theme selection
  • Font size
  • Content width

The current article may be stored temporarily in session storage to display in the reader tab.

Data Sharing

We do not share or sell data with third parties. When you explicitly use “Save for later” / “Send to Web App,” the article content (HTML and CSS styling) is transferred to the destination web app you open for the purpose of rendering the article.

Remote Code

The extension does not load or execute remote code. All JavaScript is bundled with the extension.

Permissions

  • activeTab: Access the current page only after the user clicks the extension icon.
  • scripting: Inject the content extraction script into the active tab.
  • storage: Save preferences and temporary article data.
  • declarativeNetRequest: Set referrer headers for CDN images to load correctly.
